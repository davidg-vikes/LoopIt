# LoopIt (Chrome Side Panel Extension)

LoopIt is a productivity-focused Chrome Extension that lives in the Side Panel and loops precise YouTube playback intervals.


## Usage

1. Open a YouTube video in a tab (or paste a URL/ID and click **Open**).
2. In LoopIt, click **Connect current YouTube tab**.
3. Add intervals (one per line): `1:30 2:00 Chorus`
4. Toggle **Repeat** to loop, or click **Jump to interval**.
5. Use **Start** / **End** to capture timestamps from the playing video.
